# レポっとアーカイブのビューア

ビルド不要の静的ページです。Vue 2とLeafletをCDNから読み込みます。

リポジトリのルートで次を実行し、`http://localhost:8765/` を開いて確認できます。

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs
```

## 操作

画面幅1200px以上では従来のPC画面、1200px未満ではスマホ向けの画面になります。切り替え時も、選択したデータセット・表示期間・地図の位置を維持します。

SafariのURLバー・ステータスバー・キーボードで利用できる領域が変わる場合は、VisualViewportの高さと位置をCSS・JSで共有し、ヘッダー・シート・メニュー・ダイアログを表示領域に収めます。下部の安全余白は写真一覧のスクロール領域内に設けます。ページ自体のピンチズームではレイアウトを組み直しません。

PC画面は左メニュー、上部の情報バー、左右に並ぶ地図と写真一覧で構成されます。地図と一覧の境界線はドラッグで幅を変更できます。境界線にフォーカスして、左右矢印キー、Home、Endでも調整できます。

スマホ向けの画面では次の操作ができます。

- 上部中央のデータセット名を押すと、同じ枠内に一覧が開きます。
- 右上の情報ボタンから、システム概要とデータの利用条件を表示できます。
- ロゴ・データセット選択・情報ボタンは同じ高さです。地図の拡大縮小ボタンは表示せず、ピンチ操作で拡大縮小できます。地図の権利表示は左端で上から下へ読む向きにし、背景を透過します。初期のシート位置と上部ボタンの間で上下中央に固定し、シートを動かしても移動しません。
- 写真一覧の上部にあるハンドルを上下にスワイプ・ドラッグすると、一覧の高さを3段階に変更できます。ハンドルは高さ44pxの操作領域の中央に配置し、タップでも変更できます。
- ハンドルにフォーカスして、上下矢印キー、Home、Endでも高さを変更できます。
- 写真は基本2列、画面幅700px以上では3列になります。
- 一覧上部に写真枚数、JSONのダウンロード、表示期間を表示します。期間は日付入力・年・全期間から指定できます。
- 写真を押すと地図の対象地点へ移動し、地図のマーカーを押すと一覧の対象写真へスクロールします。
- データセットの指定は `#komaruKurage` などのハッシュと、従来の `?h=komaruKurage` に対応します。両方指定した場合はハッシュを優先します。`#license` で利用条件を直接開けます。

## テスト

リポジトリのルートから実行します。外部通信や追加パッケージは不要です。

```sh
node --test tests/viewer.test.cjs
```

シートのスワイプ・高さ制限・画面回転、URLバー・キーボードによる表示領域の変化、ページのピンチズーム、履歴復帰、PCとスマホの切り替え、PCの左右幅調整、データセット切替、期間の絞り込み、地図と一覧の連動、メニュー操作、既存URLの動作を検証します。

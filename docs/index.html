データの収集方法

レポっとアーカイブで公開されている位置情報付き写真データは、市民参加型位置情報付き写真収集プラットフォーム「レポっと」を用いて収集されています。 レポっとのアプリは、創研堂合同会社によって提供されています。

レポっとオープンデータライセンス（RODL）

レポっとアーカイブで公開されている情報は「レポっとオープンデータライセンス（Repot Open Data License）」の下で提供されています。 本ライセンスは、クリエイティブ・コモンズ 表示 4.0 国際（CC BY 4.0）を採用しており、クレジットの表示方法として、本アーカイブ独自の簡略表示とCC BY 4.0形式の詳細表示を用意しています。

利用できること

データの利用者は、「レポっと」およびその協力者をクレジット表記することを条件として、営利・非営利を問わず、複製、改変、再配布、公衆送信等を含む二次利用を行うことができます。 その他の利用条件については、CC BY 4.0のライセンス条項に従ってください。

レポっとアーカイブについて

本システムについて

レポっとアーカイブは、市民参加型位置情報付き写真収集プラットフォーム「レポっと」によって収集されたデータを一般公開するデジタルアーカイブです。

背景地図のデータ

背景地図はOpenStreetMapの地図データをもとに、写真や投稿地点が見やすい配色で表示しています。

日本の詳細地図

Japan PMTilesで配布されている日本の地図データを利用し、レポっとアーカイブの地図配信サーバーから配信しています。

国外・広域表示

国外や広い範囲を表示するときは、OpenFreeMapの世界地図を利用します。日本の地図に収録されていない地域も、この世界地図で補います。

地図の権利表示・ライセンス

OpenFreeMap · © OpenMapTiles · Data from © OpenStreetMap contributors

地図データはOpen Database License（ODbL）に基づき提供されています。詳しくはOpenStreetMapの著作権・ライセンス情報を参照してください。

写真・投稿データの利用条件は、データの利用について（© repot contributors）で確認できます。

使用しているライブラリ

  • MapLibre GL JS
  • PMTiles

データの使い方

JSONデータを取得する

データセットを選び、写真一覧の「JSON」からダウンロードできます。JSONには、そのデータセットで公開されている全期間の投稿が含まれます。画面の表示期間による絞り込みは、ダウンロードするJSONには適用されません。

公開URLから直接取得することもできます。データセットを選択し、ダイアログを閉じた状態のページURLで、#以降にある文字列がデータセットIDです。次のURLのkomaruKurageを、取得したいIDに置き換えてください。

https://repot-archive.cocolab.jp/data/json/komaruKurage.json

例：困クラゲのJSONを開く

JSONの見方

JSONは、1件の投稿を1つのオブジェクトとする配列です。新しい日時の投稿から順に並びます。困クラゲのデータの1件を例にすると、次のような構成です。

[
  {
    "slug": "20250729143622_535a7",
    "timestamp": 1753767382,
    "filename": "20250729143622_535a7.png",
    "caption": "SO-51A ・ f/1.7 ・ 1/93 ・ ISO64",
    "location_lat": 34.25955,
    "location_lng": 133.20004,
    "location_alt": 0,
    "location_acc": 0,
    "hashtag_names": ["fromCameraRoll"],
    "caution_flag": false
  }
]
slug
投稿を識別するIDです。
timestamp
日時をUNIX時間の秒数で表します。JavaScriptで日付に変換する際は1000倍します。上の例は日本時間の2025年7月29日14時36分22秒です。
filename
画像ファイル名です。拡張子を含め、この値をそのまま画像URLに使います。
caption
説明文や撮影情報です。情報がない場合はnullです。
location_lat / location_lng
緯度・経度
location_alt / location_acc
高度・位置精度に関する補足情報です。未取得・不明の値を含みます。
hashtag_names
追加のハッシュタグを文字列の配列で表します。データセット自身の名前と「利用上の注意」は省かれています。
caution_flag
trueは「利用上の注意」が付いた投稿です。利用前に写真の内容や説明、利用条件を確認してください。

緯度・経度の組が(-1, -1)または(0, 0)の投稿は、位置情報の欠損値を表します。nullなどの値も確認し、地図への表示や位置の集計では除外してください。

画像にアクセスする

次のURLの末尾に、JSONのfilenameを付けます。画像を表示する用途にはサムネイル、より大きな画像を取得する用途には元画像のURLを使えます。

サムネイル
https://data.cocolab.jp/repot-thumb/{filename}
元画像
https://data.cocolab.jp/repot/{filename}

上の投稿の画像：サムネイルを開く ／ 元画像を開く

ブラウザで表示する場合は、画像URLをimg要素のsrcに指定します。

<img
  src="https://data.cocolab.jp/repot-thumb/20250729143622_535a7.png"
  alt="困クラゲの投稿写真"
>

JavaScriptで取得する例

JSONを取得し、それぞれの投稿に日本時間の日時と画像URLを付ける例です。

const response = await fetch(
  "https://repot-archive.cocolab.jp/data/json/komaruKurage.json"
);
if (!response.ok) throw new Error("HTTP " + response.status);

const posts = await response.json();
const items = posts.map(post => ({
  ...post,
  dateJst: new Date(post.timestamp * 1000).toLocaleString(
    "ja-JP", { timeZone: "Asia/Tokyo" }
  ),
  thumbnailURL: "https://data.cocolab.jp/repot-thumb/"
    + encodeURIComponent(post.filename),
  photoURL: "https://data.cocolab.jp/repot/"
    + encodeURIComponent(post.filename)
}));
console.log(items);
